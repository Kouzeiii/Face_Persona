2. Face-based prediction

{% if face %}

Step A — Facial features (HOG)

The face is cropped, converted to grayscale and resized to 128×128 px. HOG measures the direction of edges in small 8×8 px cells and produces a vector of {{ face.hog.length }} numbers, normalized so its length is ‖x‖ = {{ face.hog.norm }}. Range: {{ face.hog.min }} to {{ face.hog.max }}, mean {{ face.hog.mean }}.

First 10 values: {{ face.hog.first_values|join(', ') }}

Step B — Standard scaling

Each feature is compared with the average of the training data: z = (x − mean) ÷ std. Example for the first 5 features:

Step C — PCA (512 → {{ face.pca|length }} numbers)

PCA summarizes the 512 scaled features into {{ face.pca|length }} "principal components" that capture the main patterns of variation between faces (together {{ face.pca_total_variance }}% of the variation in the training faces).

Step D — Random Forest ({{ face.n_trees }} decision trees)

Each of the {{ face.n_trees }} trees (max depth {{ face.max_depth }}) looks at the {{ face.pca|length }} PCA numbers and makes its own guess for each trait. The final prediction is the average of all {{ face.n_trees }} guesses: prediction = (tree₁ + tree₂ + … + tree{{ face.n_trees }}) ÷ {{ face.n_trees }}.
