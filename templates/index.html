Multimodal Analytical Pipeline

Dual-stream methodology: facial feature extraction paired with a personality reference (biography or questionnaire)

01 Subject Ingestion
Multimodal Ingestion
A clear face photo plus a biography (public figures) or a 10-item BFI-10 questionnaire (private participants). Photos are screened for explicit content, AI generation, and face clarity.
Photo + Biography or BFI-10
→
02 Computer Vision
Facial HOG Extraction
OpenCV Haar Cascade locates the face; the crop is resized to 128×128 px and HOG measures edge directions in 8×8 px cells. The first 512 HOG values are kept and normalized.
512 HOG Values (Normalized)
→
03 Personality Reference
Reference OCEAN Scoring
Public figures: Claude AI rates the biography on each Big Five trait (0–100). Private participants: scores are computed from their own BFI-10 answers.
OCEAN Reference Scores (0–100)
→
04 Machine Learning
Cross-Modal ML Prediction
Features are scaled and reduced by PCA (10 components); a Random Forest (200 trees, trained on the 103-subject baseline) predicts OCEAN from the face, then compares it with the reference scores.
Random Forest + Agreement Check
